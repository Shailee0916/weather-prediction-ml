# 🌦️ Weather Prediction ML App

## 📌 Overview

This project is an end-to-end Machine Learning application that predicts weather conditions based on historical data.

---

## 🚀 Features

* 📊 Exploratory Data Analysis (EDA)
* 🤖 Machine Learning Models
* 📈 Model Comparison
* 🔮 Weather Prediction
* 📉 Explainability (SHAP - coming soon)

---

## 🧠 Models Used

* Logistic Regression
* Random Forest ✅ (Best Model)
* XGBoost

---
